# Spec Kit course kit: Daily Orders exercise

Companion files for the guide *Spec-Driven Data Pipelines with Spec Kit + Claude Code*.

| Path | What it is | Used in |
|---|---|---|
| `data/incoming/` | 4 sample CSV files with planted data problems | Sitting 3 (copy into your project) |
| `starter/constitution-starter.md` | Draft constitution to edit | Sitting 3, Step A |
| `reference-solution/` | Working pipeline + 12 tests + expected results | Sitting 3, Step E |
| `tools/generate_sample_data.py` | Regenerates the sample data; lists every planted issue | Optional |

**Do not** copy `reference-solution/` into your Spec Kit project before you finish
Step D - the point of the exercise is to let the spec-driven workflow produce the code.
